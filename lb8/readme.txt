Лабораторная работа № 8 «Интерполяция изображений»

Программа выполняет три аффинных преобразования:
1. Масштабирование по X и Y.
2. Поворот на заданный угол.
3. Скос по оси X.

Для каждого преобразования можно выбрать один из методов интерполяции:
ближайший сосед, билинейная или бикубическая интерполяция.

Запуск:
    pip install -r requirements.txt
    python lab8.py

Для демонстрации в отчёте использованы параметры:
масштаб 1,5 × 1,5 — ближайший сосед;
поворот 30° — билинейная интерполяция;
скос 0,35 — бикубическая интерполяция.
