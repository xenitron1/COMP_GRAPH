Лабораторная работа 4, вариант 12

Задание: по заданным длинам сторон вывести треугольник и его вневписанные окружности.

Дополнительные требования:
1. Длины сторон получаются из первых трех отрезков line в SVG.
2. Результат можно сохранить в текстовый PBM P1.

Порядок работы:
1. Открыть example_lab4.svg или свой SVG.
2. Нажать Построить.
3. При необходимости сохранить PNG.
4. Нажать PBM для текстового файла.
