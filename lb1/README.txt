Лабораторная работа №1 — вариант 12
Python / Tkinter / Linux / Windows

Что умеет программа:
- открыть изображение;
- обработать его по варианту 12;
- сохранить обычное изображение;
- сохранить текстовый PBM-файл в формате P1.

Вариант 12:
1. RGB (64, 64, 127) — левый верхний угол;
2. RGB (127, 64, 127) — правый верхний угол;
3. RGB (127, 127, 64) — правый нижний угол.

Запуск в Linux:

1. Установить Python 3.
2. Если Tkinter отсутствует:
   Ubuntu/Debian:
   sudo apt install python3-tk

3. Установить Pillow:
   python3 -m pip install -r requirements.txt

4. Запустить:
   python3 lab1_variant12.py

Формат PBM:
Программа сохраняет ASCII PBM (P1).
В файле:
P1
ширина высота
последовательность 0 и 1

В PBM:
1 = чёрный пиксель
0 = белый пиксель

Цветное изображение перед записью в PBM преобразуется в чёрно-белое
по яркости с порогом 128.
